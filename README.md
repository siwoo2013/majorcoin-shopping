# 메이저코인 쇼핑몰 V2.0

기존 Blog24 Pi Shopping V1.6.20을 기준으로 일반 쇼핑몰 구조로 전환한 버전입니다.

## 변경사항
- Pi SDK / Pi 로그인 / Pi Testnet 결제 제거
- 일반 회원가입/로그인 추가 (아이디, 비밀번호, 이름, 연락처)
- 상품 가격/배송비 단위를 원화로 변경
- 쇼핑몰 포인트 결제 구조 추가
- 포인트 부족 시 충전 안내창 추가
  - 10만원 → 100,000P
  - 30만원 → 330,000P
  - 50만원 → 550,000P
  - 100만원 → 1,100,000P
- 충전방법: 코인 충전 / 현금이체 충전 선택
- 회원 포인트 원장(point_ledger) 및 충전요청(recharge_requests) DB 추가
- 기존 상품/장바구니/배송/주문/관리자/엑셀 기능 최대한 유지

## 중요
현재 코인 충전은 거래소 API/입금주소가 아직 지정되지 않았으므로 '충전요청 생성' 단계까지 구현되어 있습니다. 다음 버전에서 운영자가 사용할 거래소와 메이저 코인 주소/API를 연결하면 자동 입금확인 및 포인트 적립을 붙일 수 있습니다. 현금이체도 은행 API 또는 입금감지 방식을 결정한 뒤 자동 적립을 연결합니다.

## Render 환경변수
- DATABASE_URL : PostgreSQL
- ADMIN_KEY : 관리자 로그인 키
- SITE_URL : 선택 사항

PI_API_KEY는 더 이상 사용하지 않습니다.


## V2.2 변경사항
- 메인 슬라이드 1/2 메이저코인 이미지 적용
- DB 없이 로그인 가능한 샘플회원: tttt / 3333 (포인트 0P)
- Pi 보라색 계열을 골드/브론즈 테마로 변경
- Pi SHOP/Pi Shopping 샘플 이미지 제거 및 메이저코인 브랜딩 적용


## V2.3
- 관리자 가상자산 입금주소 입력줄 추가/삭제/사용 ON/OFF
- 입금주소가 등록되고 ON인 코인만 상품 카드/상세에 노출
- 빗썸 Public Ticker로 KRW 상품가격을 코인 수량으로 환산 표시
- 표기: BTC 0.001234 / ETH 0.053210 / USDT 182.22
- 시세 60초 갱신, 실제 결제는 쇼핑몰 포인트 기준


## V2.4
- 관리자 `가상자산 설정` 탭 실제 연결 확인
- 기본 파킹 주소 3종 내장: USDT(TRC20), TRX(TRC20), ETH(Ethereum)
- DB 미연결/빈 DB에서도 기본 3종 주소 자동 노출
- 관리자에서 추가 주소를 저장할 수 있으며, 기본값은 버전업 시에도 코드에 유지
