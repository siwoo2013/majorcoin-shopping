# 메이저코인 쇼핑몰 V2.0

기존 Blog24 Pi Shopping V1.6.20을 기준으로 일반 쇼핑몰 구조로 전환한 버전입니다.

## 변경사항
- Pi SDK / Pi 로그인 / Pi Testnet 결제 제거
- 일반 회원가입/로그인 추가 (아이디, 비밀번호, 이름, 연락처)
- 상품 가격/배송비 단위를 원화로 변경
- 쇼핑몰 포인트 결제 구조 추가
- 포인트 부족 시 충전 안내창 추가
  - 10만원 → 100,000P
  - 30만원 → 330,000P
  - 50만원 → 550,000P
  - 100만원 → 1,100,000P
- 충전방법: 코인 충전 / 현금이체 충전 선택
- 회원 포인트 원장(point_ledger) 및 충전요청(recharge_requests) DB 추가
- 기존 상품/장바구니/배송/주문/관리자/엑셀 기능 최대한 유지

## 중요
현재 코인 충전은 거래소 API/입금주소가 아직 지정되지 않았으므로 '충전요청 생성' 단계까지 구현되어 있습니다. 다음 버전에서 운영자가 사용할 거래소와 메이저 코인 주소/API를 연결하면 자동 입금확인 및 포인트 적립을 붙일 수 있습니다. 현금이체도 은행 API 또는 입금감지 방식을 결정한 뒤 자동 적립을 연결합니다.

## Render 환경변수
- DATABASE_URL : PostgreSQL
- ADMIN_KEY : 관리자 로그인 키
- SITE_URL : 선택 사항

PI_API_KEY는 더 이상 사용하지 않습니다.

- DB 없이 로그인 가능한 샘플회원: tttt / 3333 (포인트 0P)
